# Optimization-Playground-Web-App

Interactive numerical methods visualization tool built with **Shiny for Python**.

This project explores **Gradient Descent** on several objective functions:

- Quadratic Bowl
- Rosenbrock Function
- Saddle Point

Users can adjust:

- objective function
- learning rate
- iterations
- starting point

Outputs include:

- contour plot + optimization path
- loss vs iteration
- gradient norm vs iteration
- convergence/divergence diagnostics

## Run locally

Install requirements:

```bash
pip install -r requirements.txt
```

Run:

```bash
shiny run --reload app.py
```

## Features

- Interactive gradient descent visualization
- Dynamic learning-rate ranges by objective function
- Numerical diagnostics
- Educational numerical methods interface

Built using:

- Python
- Shiny for Python
- NumPy
- Matplotlib
